Meowdoku is a logic puzzle that blends Sudoku and Minesweeper. The objective is to place a single cat into every colored square on the grid based on four core rules.The 4 Rules of MeowdokuOne Cat Per Region: Every colored area must contain exactly one cat.No Same Row or Column: No two cats can be in the same row or the same column. Once a cat is placed, you can cross out all other empty cells in its row and column.No Diagonal Contact: Cats are loners. They cannot touch each other, even diagonally. One cat blocks all eight surrounding cells, keeping them separated.No Guessing: Every puzzle is built to be solved using logic. If you ever get stuck, look for areas where a color or row is entirely out of valid spaces, revealing exactly where a cat must go.
