How to play Meowdoku
  • One cat per region: every colored area must contain exactly one 🐱.
  • No shared row or column: no two cats can occupy the same row or column.
  • No diagonal contact: cats cannot touch each other, even diagonally.
  • No guessing: every puzzle is logically solvable. If you're stuck, look for a region, row, or column with only one valid cell remaining.

Left-click marks a cell as "no cat" (✕). Left-click again to promote to 🐱. Right-click goes straight to 🐱. Use the mode toggle to swap which action comes first on tap — handy on mobile.
