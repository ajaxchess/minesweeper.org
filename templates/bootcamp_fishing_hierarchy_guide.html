Fishing & Decision Hierarchy — Pattern Guide

Level 7 · When obvious moves run out, subtract constraints to find the hidden answer.

Level 7 boards are in a stuck state — every tier-1 move (flag provable mines, click provable safes) has already been made. Nothing looks obvious. But the answer is still there: two number constraints that overlap in a way that lets you subtract one from the other and prove a cell safe. This is called fishing.

Concept The decision hierarchy — try in order before guessing

Expert players follow a hierarchy when deciding what to do next. Going straight to guessing is a sign that a logical move was missed. Level 7 trains the second tier:

1
Tier 1 — already done
Flag every provable mine. Click every provably safe cell. Repeat until nothing is left.
✓ done
2
Tier 2 — fishing (this drill)
Find a pair of constraints where one is a subset of the other. Subtract to deduce mines or safe cells that tier-1 couldn't find.
← now
3
Tier 3 — probabilistic guess
If no logical move exists at all, pick the cell with the lowest mine probability.
last resort

Fishing Subset deduction — subtract a smaller constraint from a bigger one

Two revealed numbers may share hidden cell neighbors. When one number's hidden-neighbor set is a strict subset of another's, you can subtract the smaller constraint from the larger to isolate the "remainder" cells and count their exact mine total.

The fishing pattern

  1. Find a number A with hidden neighbors {X, Y, Z} and value 2.
  2. Find a number B whose hidden neighbors {X, Y} are a strict subset of A's, with value 1.
  3. Subtract: {Z} = A − B has 2 − 1 = 1 mine. Z is a mine — flag it.
  4. Now check: does flagging Z make any number chord-ready? If so, chord to reveal safe cells.
💡 The subtraction also works in reverse: if A has value 1 and B (subset) has value 1, then the remainder has 0 mines — those "remainder" cells are safe.

Strategy How to search for fishing opportunities

Scan the frontier systematically — look for number pairs where one's hidden set contains the other's:

Pair up
For each frontier number, list its hidden neighbors. Find another number whose hidden set is a subset or superset.
→
Subtract
Smaller set value subtracted from larger set value → mine count of the remainder cells.
→
Act
If remainder = 0 mines → click those cells. If remainder = cell count → flag them. Then chord what opens.

Level 7 is the hardest bootcamp drill because the answer is never on the surface. The two constraints that crack it might be far apart on the board — train your eye to scan for overlapping hidden-neighbor sets, not just single numbers.
